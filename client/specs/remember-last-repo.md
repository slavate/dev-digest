# Remember Last Repo — client

## Проблема
`/` завжди редіректить на перший репозиторій (`repos[0]`), хоча перемикач уже пише вибір у
`localStorage["dd-repo"]`. Домашня сторінка цей вибір ігнорує.

## Поведінка
- `/` відкриває `/repos/<останній репо>/pulls`. Немає збереженого → перший репо. Репо немає → empty state (як зараз).
- «Останній» = репо з URL `/repos/:repoId/...`, на якому був користувач, або вибраний у перемикачі.
- Збережений id, якого вже немає (репо видалено), ігнорується → перший репо.
- Невідомий `:repoId` в URL не зберігається.

## Реалізація
- `lib/repo-context.tsx` `RepoProvider`: `repoId = fromPath ?? (stored, якщо є в списку) ?? list[0]`;
  ефект зберігає `fromPath`, коли це відомий репо.
- `app/page.tsx`: редірект і кнопка беруть `activeRepo` з `useActiveRepo()` замість `repos[0]`.
- Без змін на сервері: один локальний користувач, `localStorage` достатньо.
